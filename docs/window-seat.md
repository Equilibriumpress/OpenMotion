# Window Seat · Parallax Cinema

First production: Japan by Train, 40 seconds, 1080 × 1920, 60fps. Seven original runtime-drawn shots. No raster assets, new dependencies or automatic MP4 rendering.

The `parallax-cinema` layout uses `parallax.shot`, `speed` (0–2) and `episode`. The shared Canvas frame renderer draws horizon, mountain, hills, fields, buildings, poles and foreground at independent time-derived speeds. The rail exterior changes into a cabin view. Blossoms and station lighting are procedural. The shared browser audio mixer and Studio playback use the same synthesized stereo audio buffer. The train and landscape are stylized fictional illustrations, not a mapped route.

Open `#studio/window-seat-001-japan-by-train`. Select an opening frame for social cover. Export using the regular Studio MP4 workflow. Series and episode SVG covers are distinct. Before approval, check the scene boundaries at 4, 10, 17, 24, 31 and 37 seconds, playback and export in Safari/Chromium, and audio track presence. No added test Actions or build steps.
