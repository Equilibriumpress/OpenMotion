# Publication export EXP-01–10
Default: 1080p at project 30/60 fps, H.264 target 12/20 Mbps and AAC-LC 192 kbps 48 kHz stereo. No implicit resize or MediaRecorder fallback in publication mode. Check encoder support in Studio before rendering. If AAC is unavailable, explicit draft mode can retain frame-by-frame H.264 and provide WAV separately. If H.264 is unavailable, draft may use MediaRecorder. Drafts are not publication masters.
Preview, browser renderer and manual FFmpeg master use mixProjectAudio. Source failures and silent mixes are errors; peak normalization prevents digital clipping. Browser metadata checks encoded dimensions, frame timing, duration and audio track presence; audibility of the encoded track and visual quality still require playback. Manual workflow accepts any stored slug; PNG frame transfer avoids intermediate JPEG compression, and FFprobe checks the finished file. No extra automatic workflow or server render.
Device acceptance: on iPad Safari choose 1080p/30 then 60 fps, check capabilities, render Living Travel Posters and a voice-over episode, verify playback and sync. If the codec is unavailable use the manual workflow for that slug. No promise of native AAC availability on every device.
