# Character Studio 1.0

Open #character-studio. The existing Presenter Lab remains accessible via #presenter-lab. Character Studio extends the shared comparison timeline, not a separate renderer.

## Source and assets
Avatar Studio by Rohit Biradar, MIT, https://github.com/memoriesrohit/avatar-studio, pinned revision 2fd9ec82fbe1613d40ae38aadcca3f410725f740. Catalog and modular garment conventions are adapted from js/catalog.js and js/scene.js. The 20 rigged models are derived from Microsoft Rocketbox (MIT, © 2020 Microsoft). Complete license notices: public/character-studio-licenses.txt. Models load lazily from the pinned jsDelivr GitHub CDN; 11–13 MB per model according to upstream documentation. No new npm package or automated model build. No generated images. The original source includes its own editor and GLB export; this integration implements preset and video export, not that editor's complete 3D file export or material/HDRI pipeline.

## Editor
Select one of 20 people, formal/original/shirt/tee, garment tint, black/blue trousers, one of ten expressions and one of 13 native motion clips. The model determines hair and facial geometry; this is not a sculpting or hair editor. Clothes recolor only on modular garment meshes. The live comparison uses the original pilot narration and captions. Save named presets in localStorage, export/import a JSON preset, apply it to the pilot in the browser, or download project.json for durable GitHub storage. Browser changes are local and may be replaced by the deployed manifest on reload; commit the downloaded project JSON to GitHub for persistence. The 3.0 series template includes the default Alex, based on Sophia (same Business_Female_04 source as the previous 3D experiment), forest-green suit. The template is the source of truth for subsequent episodes. Other series are not automatically compatible; they need the clean editorial renderer.

## Rendering
The existing Three.js renderer loads one selected GLB at a time, disposes it on replacement, applies outfit groups and expression morphs, samples native animation clips at absolute scene time and composites a fixed lower-left portrait into Canvas. ARKit mouth approximations use the existing generated voice-energy and spelling-derived viseme frames. The neural live Talking Avatar demo remains separate; no exact phoneme or neural alignment is claimed. Browser MP4 uses the existing exporter and fails on missing model, narration or speech data. Original Alex 1.1 and 2.0 and the previous Rocketbox model remain selectable in Presenter Lab. The main pilot is updated to version 3.0, status review. No extra test Actions.

## Acceptance
Open the pilot and verify the actual model, clothing groups, face crop, mouth movement and captions at scene cuts; compare the old model in Presenter Lab. Try all 20 model URLs, garment combinations and animation clips. Check model load errors and memory on iPad. Render publication 1080x1920/30fps and verify audio and actual frame dimensions. The model binary files and runtime were not tested in the local environment. If the CDN or browser fails, use the existing original Rocketbox mode in Presenter Lab and revert the pilot to the previous template if needed. No cross-series selector or independent voice assignment is implemented in this iteration.
